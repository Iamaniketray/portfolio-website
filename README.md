# Aniket Kumar — Portfolio

A responsive, single-page portfolio for Aniket Kumar, focused on Cloud, DevOps, DevSecOps, and AI/ML engineering.

## Run locally

Open `index.html` in a browser, or serve the `portfolio-website` directory with any static file server. The page has no build step or package dependencies.

## Included

- Resume-based profile, education, internship, fellowship, skills, projects, and achievements.
- Existing project links, certifications, contact details, and profile photo.
- Responsive navigation, accessible light/dark theme toggle, scroll reveals, and email-compose contact form.
